## Who This Is For

This guide is for **backend developers** who:

- Have **zero or minimal frontend experience**
- Range from **junior to senior backend level**
- Are strong in logic, APIs, and architecture — but new to UI, browser behavior, and frontend ecosystems
- Want to become a **full-stack developer** or better collaborate with frontend teams

## How to Use This Guide

1. **Start with [Frontend Fundamentals](/fundamentals/)** — understand the landscape before writing code
2. **Follow the [Roadmap](/roadmap/beginner/)** — go level by level, don't skip ahead
3. **Deep-dive into [Key Concepts](/concepts/html/)** — reference these as you encounter new topics
4. **Use the [Practical Guide](/practical/project-structure/)** — apply what you've learned on real code
5. **Check [Best Practices](/best-practices/)** — write frontend code that your team will respect
6. **Follow the [Fast-track Plan](/fast-track/)** — if you're in a hurry, this tells you what to prioritize

:::tip[Backend developer advantage]
You already understand the hard parts: APIs, data modeling, async operations, and system design. Frontend will feel approachable — it's mostly about learning a new rendering environment and a different kind of state management.
:::
