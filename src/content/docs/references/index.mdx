## Official Documentation

The primary references you'll return to again and again.

<CardGrid>
  <Card title="react.dev" icon="star">
    Official React documentation with interactive tutorials. The best place to learn React from scratch or look up any API.

    [react.dev →](https://react.dev)
  </Card>
  <Card title="MDN Web Docs" icon="document">
    The authoritative reference for HTML, CSS, and JavaScript. When in doubt, check MDN.

    [developer.mozilla.org →](https://developer.mozilla.org)
  </Card>
  <Card title="javascript.info" icon="pencil">
    The best free, in-depth JavaScript book online. Covers fundamentals through advanced topics with clear examples.

    [javascript.info →](https://javascript.info)
  </Card>
  <Card title="Vite Docs" icon="rocket">
    Project setup, configuration, and build tooling. Start here when scaffolding a new React project.

    [vite.dev/guide →](https://vite.dev/guide/)
  </Card>
  <Card title="TypeScript Handbook" icon="approve-check-circle">
    The official TypeScript documentation — from basic types to advanced generics.

    [typescriptlang.org →](https://www.typescriptlang.org/docs/handbook/intro.html)
  </Card>
  <Card title="Tailwind CSS Docs" icon="puzzle">
    Utility-first CSS framework used in Code & Craft. The search bar in the Tailwind docs is the fastest way to find a class.

    [tailwindcss.com/docs →](https://tailwindcss.com/docs)
  </Card>
  <Card title="Zustand Docs" icon="bars">
    Simple, minimal global state management — covered in the intermediate and advanced roadmaps.

    [docs.pmnd.rs/zustand →](https://docs.pmnd.rs/zustand/getting-started/introduction)
  </Card>
  <Card title="TanStack Query Docs" icon="forward-slash">
    Server state management library for async data fetching, caching, and synchronization.

    [tanstack.com/query →](https://tanstack.com/query/latest)
  </Card>
</CardGrid>

## Interactive Practice

Learn by doing — games and hands-on tools for building muscle memory.

- [Flexbox Froggy](https://flexboxfroggy.com) — Learn CSS Flexbox by moving frogs with CSS properties
- [CSS Grid Garden](https://cssgridgarden.com) — Learn CSS Grid layout by growing carrots
- [Total TypeScript](https://www.totaltypescript.com/) — Matt Pocock's interactive TypeScript exercises, from beginner to advanced
- [React Developer Tools](https://react.dev/learn/react-developer-tools) — Browser extension (Chrome/Firefox) to inspect React component trees and state

## Blogs & Deep Reads

Long-form articles and blogs worth bookmarking.

- [Josh W Comeau's blog](https://www.joshwcomeau.com/) — Visually rich deep-dives into CSS animations, React internals, and layout fundamentals
- [Overreacted (Dan Abramov)](https://overreacted.io/) — Core React mental models, written by one of React's original team members
- [CSS-Tricks](https://css-tricks.com/) — CSS guides, a complete flexbox/grid almanac, and practical layout references
- [web.dev](https://web.dev/) — Google's hub for web performance, Core Web Vitals, and accessibility best practices
- [toidicodedao.com](https://toidicodedao.com/) — Vietnamese developer blog covering fundamentals, architecture, and career topics
- [200lab.io](https://200lab.io/) — Vietnamese tech blog and courses, including frontend and fullstack content

## Tools & Utilities

Small tools you'll use while building.

- [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/) — Verify text/background color contrast ratios against WCAG accessibility standards
- [Chrome DevTools Docs](https://developer.chrome.com/docs/devtools/) — Official reference for every panel in Chrome DevTools
- [JSONPlaceholder](https://jsonplaceholder.typicode.com) — Free fake REST API for testing and prototyping (used in practice projects)
- [Open-Meteo](https://open-meteo.com/) — Free, no-auth weather API — great for building data-fetching practice projects
