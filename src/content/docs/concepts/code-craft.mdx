## About This Course

**Code & Craft: Intro to Front-End Development** is the TEQ team's beginner-focused course for anyone starting their frontend journey. It walks through the core languages — HTML, CSS, and JavaScript — then moves into building responsive, interactive websites with React, Next.js, and Vue.

<Aside type="tip" title="Perfect starting point for backend developers">
If you have zero frontend experience, start here. This course covers the exact foundation this guide is built on — HTML, CSS, JS, and your first React app — in a structured, instructor-led format created by the TEQ Front-end team.
</Aside>

## What's Inside

### Module 1 — How to Become a Front End Developer

An 8-week training program roadmap for participants with prior knowledge of HTML, CSS, and JavaScript. Covers the pathway from fundamentals to building with React (Vite), Next.js, and Vue.

| Lesson | Description |
|---|---|
| Template | The 8-week training template and program structure |

### Module 2 — Modern Front-End Mastery: React, Vue, Next.js & Beyond

Hands-on lessons through today's most in-demand frontend frameworks.

| Lesson | Description |
|---|---|
| React Ready: Fast Front-End Development with Vite | Learn React with Vite — component-based UI development with blazing-fast HMR |
| Build a Custom CMS: Next.js & NextAuth in Action | Build a fully functional CMS secured with NextAuth authentication |
| Next-Level Web Apps: Mastering SSR & SEO with Next.js | Server-side rendering, SEO optimization, and performance with Next.js |
| Vue Mastery: Building a Weather App with Vue.js | Build a data-driven, reactive weather app using Vue's intuitive syntax |
